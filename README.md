# DormMate
A student-focused housing mobile application designed to simplify the search for dormitories, condos, and compatible roommates.

DormMate is an academic project developed in partial fulfillment of the course requirements for ITISMOB *[MOBDEVE - Mobile Development]*.

# Features
- Authentication - Register and log in to an account
- Dormitory Listings - Browse available dormitories and condominiums
- Search and Filters - Find dorms based on location, price, and preferences
- Roommate Matching - Discover potential roommates with compatible preferences
- In-App Messaging - Communicate with connected roommates through in-app chat
- Student Profiles - Create and manage personal profiles
- Dormitory Listing Management (Landlords/Dorm owners) - Create, update, view, and manage property listings

# Installation and Setup
## Prerequisites 
- Android Studio
- Git
- Minimum SDK support to API 24
- A compatible JDK

### Setup
1. Clone the repository
```bash
git clone https://github.com/geezerbeez/DormMate.git
```
2. Open the cloned DormMate folder in Android Studio and wait for Gradle Sync to finish
3. Select an emulator or connect an Android device
4. Click the Run button and wait for the application to build and launch
